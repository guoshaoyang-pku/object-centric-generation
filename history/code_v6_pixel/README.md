# Supplementary raw-pixel64 conditional flow

This branch answers the raw-pixel comparison question. It does not replace or revise the registered three-way native128 experiment. Future RGB is bilinearly resized from128 to64 with align_corners=False, antialias=False. Every channel is standardized using one global mean/std computed over all9749 training future clips; no validation/test arrays enter the statistics. The statistics manifest binds every training source SHA.

The prediction target is20 frames ×8×8 spatial patches ×192 RGB patch values:1280×192=245760 scalars. Packing/unpacking is an exact permutation; image decoding only reverses fixed normalization and clamps to[0,1] for display/metrics. There is no learned image decoder or future VAE encoding. The observed four-frame prefix uses the same frozen C2 initial cached-VAE adapter as the object pilots. The complete frozen prefix codec has1304358 parameters, including unused posterior/renderer preserved for strict provenance.

The generative backbone is SmallObjectFlow,384 width/8 layers/6 heads/global attention and learned slot positions. Trainable parameters23515584; total24819942. This has5.12× object token count,7.68× target scalar count, and26.2× the self-attention pair count. It is a practical equal-training-time baseline, not equal code capacity or a controlled change of only representation. The extra pixel-noise dimensions use an independent stream; the first32000 Gaussian values and flow-time primary stream match object draws at equal updates. Training samples use the same independent data RNG.

Fresh seed713, B8, AdamW1e-4,900 single-H200 training-loop seconds; evaluation/setup excluded and reported separately. Hard wall cap0.75h and global08:45 deadline. GPU launch is gated by the independent actual-GPU smoke; no GPU was launched by this implementation task.

Evaluation uses both4/16 Euler steps, seeds17/29, and real/wrong prefixes. Wrong IDs are shifted within sorted pilot32 and separately sorted showcase4. Every sample is retained; generation receives prefix context and noise only. `samples/<id>/{real_seed17,wrong_seed17,real_seed29,wrong_seed29}.npz` stores16-step FP32 latent[1,1280,192] and RGB[20,3,64,64]; real4/wrong4 files store4-step samples. `future_RGB.npz` is an arithmetic target roundtrip, never called an AE. Entire model state and frozen prefix/normalization are checked before/after inference. Final pilot32 and showcase4 averages are separate.

The common64 comparison must bilinearly downsample the other models' saved native128 RGB with the same settings; direct object querying at64 has different sampling bandwidth and should not be substituted. RGB/foreground/background/motion metrics measure recorded-target agreement, not physical-law compliance.

CPU evidence: raw_pixel_smoke/admission.json reports2step+resume3 versus continuous3 bitwise matching flow, optimizer, all RNGs, samples and protocol.32 samples cover two disjoint2-case fixtures ×all conditions/steps/seeds. Tiny training budget stops after one update and resume adds zero.8 unit tests cover packing, exact resize, count, normalization provenance, frozen weights, hidden gradients, future-target separation and primary noise/time matching. Four separate statistics tests pass. Source files copied from v5 remain byte-identical; only raw modules/tests are new.
